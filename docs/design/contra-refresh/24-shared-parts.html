The shared parts

Phase 1 of the migration: the components imported by most of the app, drawn with the classes that are in production.

Shipped
Eight components, and most of the app changed.
ChipButton is imported by 54 files, BackLink by 54, Input by 47. They went before any page did, because a page migration that starts with the shared parts already right is only about structure.

The four icon tints — iconPrimary, iconSecondary, iconTertiary, iconInverse — are gone. They held their own greys off the ramp, and iconSecondary was the same grey in both schemes, so a dim icon in dark mode was dim against the wrong ground. 193 call sites now take ink, ink-2 or ink-3 like everything else.
The chip, and why its default changed
Tone Looks like When
neutral CopyEditShare The default now. A chip is a repeated action by nature — three on a card, five down a list — and the accent belongs to the one action a page exists for.
primary ChangeView The chip that is the page’s action. Was the default; now it has to be asked for.
filled Share A single prominent chip. Takes the gym’s colour, with the label contrast-checked against it — a yellow brand no longer gets white-on-white.
amber Needs attention Something is off but nothing has broken.
red Remove Destructive. Carries a warning haptic, not a tap.
inverse Auto-fill Ink fill for emphasis without competing with the brand.
